# AI Brief

A daily AI morning briefing: models, agents, security, research and real-world impact, in a five-minute read.

Published automatically each morning at https://quinnlutters.github.io/ai-brief/

- `YYYY-MM-DD/index.html` — one folder per edition
- `editions.json` — list of editions; `python3 build.py` rebuilds the archive `index.html`
